# Security policy

Please do not disclose vulnerabilities involving execution of untrusted update archives, the ZIP updater, GitHub publishing, or repository workflows in a public issue before maintainers can assess them.

To report privately, use **GitHub → Security → Report a vulnerability** on the repository, if private vulnerability reporting is enabled. If it is not enabled, ask the maintainer via a neutral issue for a private reporting channel without including exploit details.

Never paste access tokens or secrets into issues, PR descriptions, workflow logs, or screenshots.
