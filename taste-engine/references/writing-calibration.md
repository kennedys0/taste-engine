# Human-centered UX writing calibration

A style controls **tone**, not truth. The same form can be written bluntly in Brutalism and warmly in Claymorphism while preserving one actual state and action.

## Spot patterns, not prohibited punctuation

Common warning signals: generic abstract benefits; over-rehearsed rhythm and identical paragraphs; slogans without a user action; repeated rule-of-three bullet structures; stacked exclamation marks, emoji or em dashes used as decoration; unexplained English words in an Indonesian product; vague error messages.

Do not adopt absolute bans on words, contractions, semicolons or em dashes. None proves AI authorship. Some domain words, legal writing, accessibility labels and a user's brand voice legitimately need them. Fix **clarity, authenticity and repetitiveness**, not compliance with a detector's blacklist.

## Six-step writing review

1. **Audience/locale**: users' language and terms; match approved product voice, not a generic startup narrator.
2. **Job**: headline says what the section contains, button predicts result, helper text explains constraints.
3. **Truth**: any number, named company, promise, comparison, trust indicator or success state is evidenced.
4. **Rhythm**: scan short and long labels to remove mechanically repeated sentence forms without introducing awkward prose.
5. **Recovery**: every error says what failed and, where possible, what to do; don't assert an unverified cause.
6. **Accessibility**: meaningful links, labels and confirmations; do not obscure simple functionality with clever metaphors.

## Examples (only when features exist)

| Weak | Better | Reason |
|---|---|---|
| 'Unleash a smarter workflow' | 'Assign tasks to each project' | names task |
| 'Experience seamless payments' | 'Pay your invoice by bank transfer' | names available method |
| 'Oops! Something went wrong!' | 'Payment was unsuccessful. Try again.' | states real status and next step |
| 'You're all set!' before server reply | 'Menyimpan perubahan…' | avoids fabricated confirmation |
| 'Trusted by 10,000 teams' with no evidence | remove claim | honesty first |
| 'Click here' beside unnamed links | 'Lihat detail pesanan' | destination explicit |

## When preserving user wording

A visual restyle does not authorize rewriting approved copy. Improve only when user asked, a UI error state is unclear, or an objectively misleading claim must be flagged. Keep contractual, policy and legal strings intact unless a qualified review is explicitly requested.
