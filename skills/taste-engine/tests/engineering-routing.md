# Engineering skills — manual agent acceptance scenarios

For each test, verify both *routing* and output. Do not mark as executed without running the agent in the target harness.

| Prompt / context | Expected action |
|---|---|
| "Build a portfolio" with no brand | Ask style once then stop; no preemptive framework build |
| "Buat portfolio skeumorphsm pakai Next.js" | Skeuomorphism + hero + SEO + web interface + React performance; no style question |
| "Buat portfolio Neo-brutalism pakai Astro" | Neo-brutalism + hero + SEO + web interface; no React-only module |
| "Fix the Vue layout error" | Preserve style, run web interface checks, no React/SEO/hero auto-route |
| "Optimalkan rerender React component" | React performance; no new style question or arbitrary redesign |
| "Build a reusable React modal" | Web interface + conditional composition; no extra nested visual card surfaces |
| "Build native Expo onboarding" with style selected | Native mobile + style; no web SEO or Anime.js DOM features |
| "Buat docs SDK" | Docs writing; no style picker |
| "Animasi perpindahan list ke detail" in supported React | Inspect view transition compatibility, keep style, reduced motion; no duplicate Anime.js |
| "Deploy website ke Vercel" | No visual style question; deployment intent handling; no deployment performed without the right context |
| "Audit accessibility website" | Report path/line evidence when source exists; no claim of WCAG certification |
| "Website HTML sederhana" with style selected | Style + web quality (+ SEO if public); no npm install requirement |
| "Tambahkan SEO dashboard internal" | Clarify indexing/security boundary; never expose private pages |
| "Full viewport hero mobile" | Preserve 100svh content-safe contract and responsive focus/keyboard rules |
