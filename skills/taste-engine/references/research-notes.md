# External inspiration and originality notes (2026-11-02)

These are **design concepts independently re-expressed** for Taste Engine, not copied external reference modules. Source repositories were inspected via GitHub. Read their original docs for nuance and check versions before reusing any code.

| Source | Verified distinguishing ideas | Our adaptation | Excluded / conflicts |
|---|---|---|---|
| [Ferousco-dev/anti-slop-design](https://github.com/Ferousco-dev/anti-slop-design) | 20 modular references, named thesis, pre-emit audit, product register | On-demand references, product-specific direction, justified exceptions | No blanket ban on purple, glass, centered hero, default fonts or em dashes |
| [Nutlope/hallmark](https://github.com/Nutlope/hallmark) | 50 material themes, material separated from anatomy, `Floor / Reflex / Finish`, browser lint, redesign behavior preservation | Three quality tiers, style ≠ page anatomy, browser evidence checklist, preserve functionality | No universal house aesthetics or automatic themed roulette; user chooses |
| [jalaalrd/anti-ai-slop-writing](https://github.com/jalaalrd/anti-ai-slop-writing) | banned phrase lists, structural cadence and punctuation checks, voice calibration, factual honesty | Contextual writing calibration, strong truth checks and action-focused microcopy | No rigid punctuation/word-count bans, no claim of reliably detecting AI authorship |
| [tasteskill/tasteskill](https://github.com/tasteskill/tasteskill) | independent agent skills and optional variance/motion/density dials, image-to-code/redesign variants | Optional per-project three dials and modular style packs | No compulsory Tailwind/React/Framer Motion, indefinite pulse animation, mandatory fake organic data, or mandatory asymmetry |

## Why the differences matter

Taste Engine's central promise is user-owned taste. A fixed universal ban on glassmorphism would contradict an explicit Glassmorphism selection. Likewise, mandatory animation contradicts low-motion taste and accessibility. Some external sample-writing advice advocates realistic-sounding fabricated numbers; this violates Taste Engine's hard truth floor. No external default outranks explicit user preference and real content.
