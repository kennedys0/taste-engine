Arsitektur & Pipeline

How Taste Engine Works

Dari instruksi prompt mentah hingga kode antarmuka berstandar desainer profesional dunia — inilah 4 fase pipeline transformasi yang dijalankan oleh AI Agent Anda.

Phase 01
🎯

Archetype Discovery

Agent menganalisis domain aplikasi, audiens pengguna, dan target brand. Persyaratan dipetakan secara cerdas ke estetika optimal (misal: Fintech & Analytics → Data Cockpit, Dev Tools → Retro Terminal atau Swiss Editorial).

  • Pemetaan konteks domain otomatis
  • Kalibrasi tone & persona pengguna
  • Mencegah default template biru generik
Phase 02
📐

Mathematical Design Tokens

Bukan sekadar styling acak, Taste Engine menginjeksi token desain matematis: rasio tipografi terstruktur, grid spasial 4px/8px, kurva border-radius spesifik, dan peran semantik warna yang konsisten.

  • Pasangan font & scale hierarki ketat
  • Elevasi bayangan berlapis (multi-layer)
  • Variabel CSS custom properties modular
Phase 03
🌗

Paired Dark/Light Coupling

Token background, surface, ink (text), dan border bertransisi secara berpasangan matematis. Mencegah tabrakan warna fatal seperti teks hitam di background gelap atau teks putih di card terang.

  • Garansi rasio kontras WCAG AA (≥ 4.5:1)
  • Inversi otomatis via atribut [data-theme]
  • Zero manual color patching
Phase 04
🛡️

Anti-Slop Quality Gate

Sebelum menyerahkan kode, agent memverifikasi UI terhadap 7 Universal Quality Gates: tanpa card melayang tanpa ground, tanpa glow ungu murahan, tanpa glassmorphism tanpa makna, dan kelengkapan state tombol.

  • Menghapus klise estetika AI murahan
  • Memastikan hover, active, disabled state
  • Siap produksi untuk Next.js, Vue, Tailwind, dll.

Pertanyaan yang Sering Diajukan (FAQ)

Jawaban lengkap seputar cara kerja, kompatibilitas framework, aturan kontras warna, dan cara kustomisasi Taste Engine.

AI coding agents secara bawaan cenderung menghasilkan desain frontend yang seragam dan membosankan (AI-slop): bayangan ungu mengambang, kontras rendah, font tanpa hierarki jelas, dan layout generik yang terlihat murahan.

Taste Engine adalah intelligence skill pack yang membekali AI agent dengan 10 estetika terkurasi (Bento, Brutalism, Claymorphism, Cockpit, Cyberpunk, Glassmorphism, Minimalist, Retro Terminal, Skeuomorphism, Swiss Editorial) serta quality gates ketat agar hasil kodenya berstandar desainer profesional dunia.

Sama sekali tidak (100% Framework-Agnostic). Taste Engine mengajarkan agent prinsip desain murni, tokens matematis, dan formula CSS yang netral.

Anda bisa menggunakannya di React, Next.js, Vue, Svelte, Nuxt, Astro, HTML murni, Tailwind CSS, shadcn/ui, MUI, Vanilla CSS, atau UI framework apa pun yang Anda gunakan saat ini.

Setiap gaya dalam Taste Engine menerapkan aturan Strict Paired Coupling. Token warna diatur berpasangan matematis antara background, surface, ink (text), dan border.

Ketika berpindah antara [data-theme="dark"] dan [data-theme="light"], seluruh pasangan warna berganti secara simetris dan dijamin memenuhi standar kontras minimum WCAG AA (≥ 4.5:1). Aturan anti-slop secara eksplisit melarang teks hitam di background gelap atau teks putih di background terang.

Tidak. Taste Engine bersifat non-destructive dan aditif. Semua token warna dan class CSS menggunakan namespace unik seperti --taste-[style]-* sehingga terisolasi dan tidak akan menimpa CSS global Anda.

Quality gates Taste Engine juga mewajibkan agent untuk menghormati arsitektur komponen dan naming convention yang sudah berjalan di codebase proyek Anda.

Bisa! Taste Engine menyediakan 10 standalone skill independen di direktori optional-standalone-skills/. Anda bisa memasang masing-masing style secara terpisah menggunakan perintah:

npx skills add kennedys0/taste-style-[nama-style]

Misalnya: npx skills add kennedys0/taste-style-cyberpunk-hud. Cara ini sangat hemat token jika proyek Anda hanya berfokus pada 1 gaya spesifik.

Di Antigravity, Anda bisa memeriksa daftar skill yang terpasang melalui menu pengaturan atau menjalankan agy skills list di CLI.

Untuk mengujinya secara langsung di chat, cukup tanyakan: "Gunakan Taste Engine untuk mereview dan mendesain ulang komponen kartu ini dengan estetika Bento Grid." Agent Anda akan langsung mengenali dan mengaplikasikan aturan Taste Engine.

Tentu saja. Anda cukup mendefinisikan ulang variabel CSS di stylesheet Anda (misal menimpa --taste-cyber-accent: #00ffcc;).

Jika Anda ingin berkontribusi membuat style baru ke dalam pack, Anda bisa menambahkan file markdown baru di taste-engine/styles/ dan menjalankan skrip validasi resmi kami: python taste-engine/scripts/validate-pack.py.

Token Reference

Standard Token Architecture

Setiap style menggunakan konvensi token CSS yang seragam dan mudah dipetakan ke Tailwind CSS theme config atau standard CSS custom properties.

CSS Variable Pattern Semantic Role Dark Mode Behavior Light Mode Behavior
--taste-[style]-bg Canvas background layer Deep dark / OLED black tint Crisp white / soft pale tint
--taste-[style]-surface Card, panel, and modal containers Elevated dark with subtle border Clean elevated card with soft rim
--taste-[style]-text Primary readable typography High-contrast white (min 4.5:1) High-contrast slate/black (min 4.5:1)
--taste-[style]-muted Secondary labels & subtitles Medium grey (accessible contrast) Cool grey (accessible contrast)
--taste-[style]-border Card outlines & structural lines Subtle translucent white rim Subtle translucent dark rim
--taste-[style]-accent Primary action buttons & indicators Vibrant, high-chroma highlight Deep, contrast-anchored highlight
Quick Starter CSS Boilerplate 
/* Root Dark Theme Default */
:root {
  --app-bg: var(--taste-bento-bg, #0b0c10);
  --app-surface: var(--taste-bento-surface, #14171f);
  --app-text: var(--taste-bento-text, #f9fafb);
  --app-border: var(--taste-bento-border, rgba(255, 255, 255, 0.08));
  --app-accent: var(--taste-bento-accent, #6366f1);
}

/* Light Theme Transition */
[data-theme="light"] {
  --app-bg: #f8fafc;
  --app-surface: #ffffff;
  --app-text: #0f172a;
  --app-border: rgba(0, 0, 0, 0.08);
  --app-accent: #4f46e5;
}
