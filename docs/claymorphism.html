How to Install

Install Claymorphism or Full Engine

Choose whether you want this single standalone Claymorphism skill or the full 10-style automated Taste Engine suite for your AI coding agents.

Option A: Install Dedicated Claymorphism Skill

Installs only the Claymorphism style pack. Perfect if your project has already committed to this exact aesthetic and does not need a 10-style selector.

bash — universal agent skills cli
# Install standalone Claymorphism pack via Agent Skills CLI
$ npx skills add kennedys0/taste-engine --skill taste-style-claymorphism
# Or install directly for Antigravity IDE global config
$ git clone https://github.com/kennedys0/taste-engine.git && cp -r taste-engine/optional-standalone-skills/taste-style-claymorphism ~/.gemini/config/skills/

Option B: Install Full Taste Engine (All 10 Styles + SEO + Anti-Slop)

Equips your AI agent with the autonomous style router, preflight interviews, 10 aesthetic packs, full-screen hero gating, and automatic SEO audit.

bash — multi-agent native installer
# 1. Universal 1-click Agent Skills install
$ npx skills add kennedys0/taste-engine
# 2. Or install globally for Google Antigravity IDE / CLI (agy)
$ node bin/taste-engine.mjs install --agent antigravity --global
# 3. Or install for Claude Code or OpenAI Codex
$ node bin/taste-engine.mjs install --agent claude --global
$ node bin/taste-engine.mjs install --agent codex --global

Option C: Tailwind CSS & shadcn/ui Preset

Scaffold Claymorphism utility tokens directly into your React, Next.js, or Vite frontend stack.

FAQ & Verification

Frequently Asked Questions

Why is Claymorphism not considered slop? ▶
Claymorphism is an explicit material exception in Taste Engine because its depth is functional and tactile (dual inner shadows), not decorative clutter.
How does Dark Mode work in Claymorphism? ▶
In dark mode, inner specular highlights soften to subtle white tints while form shadows deepen into rich dark indigo, preserving volume.
Can I install just Claymorphism? ▶
Yes, run `npx skills add kennedys0/taste-engine --skill taste-style-claymorphism`.
