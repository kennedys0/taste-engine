bash — universal agent skills cli

FAQ & Verification

Frequently Asked Questions

Everything you need to know about Taste Engine's Claymorphism fidelity standards, anti-slop rules, and dark mode math.

Why is Claymorphism not considered AI slop?
+
Claymorphism is an explicit material exception in Taste Engine because its depth is functional, tactile, and physically coherent. Opposing dual inner shadows simulate incident light (upper-left) and form thickness (lower-right), creating tangible presence rather than arbitrary decorative glow or unreadable transparency.
How does Dark Mode maintain volumetric 3D volume?
+
In dark mode, inner specular highlights soften to delicate translucent white tints (12–18% opacity) while form shadows deepen into rich dark obsidian-indigo, preserving the pliable 3D sensation without washing out the text contrast. Text automatically pairs with pale porcelain white for verified WCAG AA accessibility.
Can I install just the Claymorphism skill for my agents?
+
Yes! Run npx skills add kennedys0/taste-engine --skill taste-style-claymorphism to equip your AI agent with only this specific aesthetic pack, or install the full Taste Engine suite for multi-style auto-routing.
What is the difference between Neumorphism and Claymorphism?
+
Neumorphism extrudes directly from the exact same background color with soft outer blur, causing severe WCAG contrast failures. Claymorphism uses distinct high-contrast surfaces, dual inner shadows for thickness, and soft ambient drop shadows that float above the canvas with distinct color boundaries and 4.5:1+ text contrast.
