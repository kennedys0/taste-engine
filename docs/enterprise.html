How to Install

Install Enterprise Skill or Full Suite

Choose whether you want this standalone Enterprise Data-first skill or the complete 10-style automated Taste Engine suite for your AI coding agents.

Option A: Install Dedicated Enterprise Data-first Skill

Installs only the Enterprise Data-first style pack. Perfect if your product is committed to high-density B2B operational cockpits.

bash — universal agent skills cli
# Install standalone Enterprise pack via Agent Skills CLI
$ npx skills add kennedys0/taste-engine --skill taste-style-enterprise
# Or install directly for Antigravity IDE global config
$ git clone https://github.com/kennedys0/taste-engine.git && cp -r taste-engine/optional-standalone-skills/taste-style-enterprise ~/.gemini/config/skills/

Option B: Install Full Taste Engine (All 10 Styles + SEO + Anti-Slop)

Equips your AI agent with the autonomous style router, preflight interviews, 10 aesthetic packs, full-screen hero gating, and automatic SEO audit.

bash — multi-agent native installer
# 1. Universal 1-click Agent Skills install
$ npx skills add kennedys0/taste-engine
# 2. Or install globally for Google Antigravity IDE / CLI (agy)
$ node bin/taste-engine.mjs install --agent antigravity --global
# 3. Or install for Claude Code or OpenAI Codex
$ node bin/taste-engine.mjs install --agent claude --global
$ node bin/taste-engine.mjs install --agent codex --global

FAQ & Verification

Frequently Asked Questions

Architectural decisions, density rules, and anti-slop boundaries for enterprise operational software.

What makes Enterprise Data-first distinct from consumer SaaS pages? ▶
Enterprise software prioritizes information density, tabular numeric alignment (tabular-nums), scannable records, sticky table headers, keyboard shortcuts, and verified SLA telemetry over giant empty cards, decorative sparklines, and marketing slogans.
Why are tabular figures (tabular-nums) mandatory? ▶
Proportional numbers vary in width, causing columns of figures to wobble visually when values update. Tabular figures enforce uniform glyph widths, allowing operators to scan numerical deltas, timestamps, and memory allocations instantly.
Can I install just the Enterprise style pack for my agents? ▶
Yes! Run npx skills add kennedys0/taste-engine --skill taste-style-enterprise to equip your AI agent with only this specific aesthetic pack, or install the full Taste Engine suite for multi-style auto-routing.
