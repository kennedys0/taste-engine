Bento Grid FAQ

Key architectural decisions behind Taste Engine's Bento Grid archetype.

Mengapa Bento Grid Taste Engine menggunakan abu-abu graphite dan bukan hitam pekat? +
Hitam murni (#000000) menciptakan kontras yang terlalu tajam dan merusak ilusi kedalaman spasial. Dengan menggunakan graphite slate hangat (#13151B untuk kanvas dan #1E222B untuk kartu), antarmuka terasa matte, mewah, mengurangi kelelahan mata, dan memungkinkan border hairline 1px (rgba(255, 255, 255, 0.08)) terlihat natural.
Apa itu aturan Two-Tone Typographic Contrast? +
Dalam Bento Grid otentik, teks headline atau narasi tidak pernah dicetak dalam satu warna solid penuh. Kalimat pembuka atau subjek utama menggunakan putih kontras tinggi (#F4F4F7 weight 700), sementara kalimat penjelas atau peran pendukung disambung dengan abu-abu hangat (#8E95A5). Ini menghasilkan hierarki baca instan tanpa kesan "tembok teks" (anti-slop).
Bagaimana Bento Grid mencegah AI-slop kartu seragam? +
Fidelity gate Taste Engine melarang keras grid seragam 3x2 dengan template kartu identik (ikon + judul + paragraf). Setiap kompartemen Bento harus memiliki anatomi internal yang berbeda: satu kartu adalah bio profil dengan avatar, kartu lain berupa tombol CTA pill kontak, kartu ketiga berisi strip capsule link, dan kartu lainnya menampilkan telemetri jam live.
Bisakah saya menginstal Bento Grid secara mandiri (standalone)? +
Ya! Jalankan perintah npx skills add kennedys0/taste-engine --skill taste-style-bento. Skill ini hanya memuat aturan, token, dan resep Bento Grid sehingga menghemat kuota context token AI agent Anda.
