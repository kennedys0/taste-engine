How to Install

Install Skeuomorphism or Full Engine

Choose whether you want this single standalone Skeuomorphism skill or the full 10-style automated Taste Engine suite for your AI coding agents.

Option A: Install Dedicated Skeuomorphism Skill

Installs only the Skeuomorphism style pack. Perfect if your project has already committed to this exact aesthetic and does not need a 10-style selector.

bash — universal agent skills cli
# Install standalone Skeuomorphism pack via Agent Skills CLI
$ npx skills add kennedys0/taste-engine --skill taste-style-skeuomorphism
# Or install directly for Antigravity IDE global config
$ git clone https://github.com/kennedys0/taste-engine.git && cp -r taste-engine/optional-standalone-skills/taste-style-skeuomorphism ~/.gemini/config/skills/

Option B: Install Full Taste Engine (All 10 Styles + SEO + Anti-Slop)

Equips your AI agent with the autonomous style router, preflight interviews, 10 aesthetic packs, full-screen hero gating, and automatic SEO audit.

bash — multi-agent native installer
# 1. Universal 1-click Agent Skills install
$ npx skills add kennedys0/taste-engine
# 2. Or install globally for Google Antigravity IDE / CLI (agy)
$ node bin/taste-engine.mjs install --agent antigravity --global
# 3. Or install for Claude Code or OpenAI Codex
$ node bin/taste-engine.mjs install --agent claude --global
$ node bin/taste-engine.mjs install --agent codex --global

Option C: Tailwind CSS & shadcn/ui Preset

Scaffold Skeuomorphism utility tokens directly into your React, Next.js, or Vite frontend stack.

tailwind.config.js — preset integration
// Add Taste Engine official presets to your Tailwind config
module.exports = {
  presets: [require('./presets/tailwind/tailwind.preset.js')],
  theme: {
    extend: {
      colors: { 'skeuomorphism': '#c88a20' }
    }
  }
};

FAQ & Verification

Frequently Asked Questions

Why is Skeuomorphism returning in modern UI? ▶
Tangible affordances provide immediate clarity for complex physical machinery, audio synthesizers, and tactile gaming tools.
How are reflections handled? ▶
Multi-stop linear gradients simulate real metallic surface reflections, paired with 1px specular highlight rims.
Can I install just Skeuomorphism? ▶
Yes, run `npx skills add kennedys0/taste-engine --skill taste-style-skeuomorphism`.
