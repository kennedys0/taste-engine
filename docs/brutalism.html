INSTALLATION GUIDE

Install Architectural Brutalism across your agent runtime. Direct execution without decorative dependencies.

# Install standalone brutalism skill into Antigravity IDE:

npx skills add kennedys0/taste-engine --skill taste-style-brutalism

Installs raw structural rules, 0px border-radius gates, stark monochrome contrast couplings, and instant hover inversion states into your agent's knowledge workspace.

# Load brutalism into Claude Code project configuration:

npx skills add kennedys0/taste-engine --agent claude-code --skill taste-style-brutalism

Enforces the brutalist material fidelity gate: requires exposed 2px–3px solid borders, rejects soft drop shadows, and guarantees immediate state flips.

# Register in OpenAI Codex instructions:

npx skills add kennedys0/taste-engine --agent codex --skill taste-style-brutalism

Injects explicit layout constraints: 0px radii, solid dividing lines, monumental typography, and signal red/yellow operational blocks.

# Link skill into Cursor .cursorrules or project prompt:

curl -sSL https://raw.githubusercontent.com/kennedys0/taste-engine/main/taste-engine/styles/brutalism.md -o .agents/brutalism.md

BRUTALISM FAQ

Core architectural principles behind Taste Engine's Architectural Brutalism style.

01 What defines Architectural Brutalism in frontend web design?
>
Architectural Brutalism (derived from Le Corbusier's béton brut or raw concrete) celebrates structural honesty: exposed 2px grid lines, pure monochrome contrast, monumental condensed grotesque typography, and zero cosmetic camouflage (no blurry drop shadows, no bubbly rounded corners, and no decorative gradients). Every element sits in an explicit, functional cell.
02 Why are borders strictly solid and 2px thick?
>
In architectural brutalism, structural joints are celebrated rather than hidden. The 2px solid border acts as the webpage's visible steel framework, dividing the canvas into uncompromising modular bays that align cleanly across desktop and mobile screens.
03 How does Brutalism differ from Neo-Brutalism?
>
While Neo-Brutalism employs playful pastel or neon pop colors, playful sticker badges, and offset hard drop shadows (e.g. 4px 4px 0px #000), Architectural Brutalism is austere, authoritative, and monotone. It uses 0px shadows, unadorned rectangular cells, and reserves saturated color exclusively for operational signal accents (Caution Yellow and Signal Red).
04 Can I install Brutalism as a standalone skill?
>
Yes. Run npx skills add kennedys0/taste-engine --skill taste-style-brutalism. This standalone package includes only the brutalist design rules, tokens, and fidelity gates, keeping your agent's context token consumption lean and efficient.
