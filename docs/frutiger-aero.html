DESIGN NOTE // MATERIAL COHERENCE

Why Coherent Lighting Defines Frutiger Aero

Authentic Frutiger Aero interfaces treat glass and acrylic as physical materials under a single directional light source. Translucent panels blur the horizon behind them, while raised buttons catch upper-left highlights and depress cleanly when clicked.

“Glass provides atmospheric lightness; tactile acrylic provides unmistakable physical affordance.”

Glassmorphism governs structural containers (translucent fills, backdrop refraction, directional edge highlights), while Skeuomorphism governs interactive controls (raised molded acrylic buttons, recessed input wells, and physical press compression).
Command wells use a compact 44px single-row container with horizontal code scrolling and a pinned Copy button so long CLI commands never wrap into oversized capsules.

MODULE A // GLASS REFRACTION 14px–22px Blur

Environmental Light Transmission

Glass panels use translucent fills over contrasting horizon layers with brighter top-left edges and cooler bottom-right borders.

MODULE B // PRESS AFFORDANCE +1.5px Travel

Restrained Physical Depression

Pressed buttons translate downward 1.5px, compress their outer drop shadow, reduce upper sheen opacity, and reveal an inset top bevel.

PASS // COHERENT AERO SYSTEM GLASS + SKEUO

Translucent glass panels over contrasting environmental layers, compact 40px–44px molded acrylic buttons with upper-left specular reflections, and single-row scrollable mobile command wells.

FAIL // ANTI-PATTERNS REJECTED

Opaque white boxes pretending to be glass, inflated plastic capsule buttons with harsh white stripes, wireframe placeholder art, or multi-line wrapped mobile command pills.
