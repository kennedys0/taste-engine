MATERIAL FIDELITY GATE

Non-negotiable screenshot-level criteria for authentic Retro Pixel interfaces

SCREENSHOT GATE
1. INTEGER PIXEL PRECISION REQUIRED

Graphics adhere to integer alignment without accidental blur. Raster pixel art uses image-rendering: pixelated. Smooth photographic blur and arbitrary vector curves without pixel logic fail this gate.

image-rendering: pixelated;
2. RETRO WINDOW SURFACES REQUIRED

Panels feature classic desktop title bars in desktop purple (#5B438E), stepped bevel shadows (2px inset highlight + 2px inset dark), and square corners (border-radius: 0px).

box-shadow: inset 2px 2px 0 #fff3, ...
3. TACTILE STEPPED FEEDBACK REQUIRED

Buttons physically displace along the integer grid on active click (transform: translate(2px, 2px)) with instant shadow collapse, providing immediate physical confirmation.

transform: translate(2px, 2px);

FREQUENTLY ASKED QUESTIONS

Engineering architecture, fidelity gates, and usability answers

DOCUMENTATION
Retro Terminal models CRT developer developer consoles, green/amber phosphor radiation, static scanline overlays, bracketed ASCII frames, and command prompt workflows. Retro Pixel models classic graphical operating systems (Windows 95 / Amiga / System 7), integer pixel illustrations, desktop purple window headers, arcade orange/teal accents, and stepped 3D pixel bevels. They are never aliased together.
Never. The style enforces a paired typography rule: chunky pixel display fonts are strictly reserved for headlines, badges, and window headers. All multi-line paragraphs, tables, inputs, and explanatory text use highly legible humanist sans-serif (Inter) or clean monospace (JetBrains Mono).
Dark mode uses a midnight navy canvas (#10102B) with desktop purple headers and vintage cream text. Light mode uses vintage cream/parchment (#F2DFB5) with warm beige window panels and midnight ink text. In both modes, tokens flip in synchronized pairs to guarantee WCAG AA contrast with zero color collision.
Taste Engine v0.11.0 includes official Tailwind tokens (colors.taste.pixel-*, boxShadow.pixel-*) in presets/tailwind/tailwind.preset.js and ready-to-use classes in presets/tailwind/taste-components.css, plus shadcn/ui theme variable overrides in presets/shadcn/shadcn-themes.css.
