Install Glassmorphism or Full Engine

Installs only the Glassmorphism style pack. Perfect if your project has already committed to this exact aesthetic and does not need a 10-style selector.

FAQ & Verification

Frequently Asked Questions

Are background gradients permitted in Glassmorphism under Taste Engine anti-slop rules? ▶
Yes! Glassmorphism has an explicit exception in Taste Engine anti-slop rules for static gradient light fields and textured backdrops. Because frosted glass requires light and structure behind it to physically refract and demonstrate translucency, harmonious gradients are material-enabling backdrops rather than decorative slop.
How does Taste Engine prevent ugly or clashing background gradients? ▶
Our architectural rules enforce strict chromatic harmony: palettes are restricted to monochromatic, analogous, or balanced complementary pairs with smooth gaussian falloff (no harsh 90s-style rainbow bands). In addition, backdrops incorporate fine tactile micro-texture (such as dot-matrix grids or subtle noise) so that the blur has crystalline grain to refract rather than flat banding.
What makes a glassmorphism implementation fail the fidelity gate? ▶
A flat solid card with a blur class where nothing is visible behind it fails. Over-blurring an entire page, low-contrast text that disappears into background light pools, or leaving dark text when switching to smoked dark glass are direct fidelity fails.
Can I install just the Glassmorphism pack without the other 9 styles? ▶
Yes! Run npx skills add kennedys0/taste-engine --skill taste-style-glassmorphism to install the standalone skill for your AI coding agent without loading the full 10-style selector.
