INSTALLATION & AGENT INTEGRATION

Choose between the dedicated standalone Minimalism skill, the full 10-style autonomous Taste Engine suite, or Tailwind/shadcn presets.

Option A: Dedicated Minimalism Style Skill

Installs only the unified Minimalism & Data Cockpit skill pack. Ideal if your project has already committed to this aesthetic and does not need the dynamic multi-style router.

bash — agent skills cli
# Install standalone Minimalism pack via universal Agent Skills CLI:
$npx skills add kennedys0/taste-engine --skill taste-style-minimalism
# Or copy directly into your Google Antigravity IDE global skills folder:
$git clone https://github.com/kennedys0/taste-engine.git && cp -r taste-engine/optional-standalone-skills/taste-style-minimalism ~/.gemini/config/skills/

Option B: Full Taste Engine (All 10 Styles + Router + SEO)

Equips your AI agent with the complete design system intelligence, automated style router, preflight interviews, anti-slop audits, and conditional SEO readiness.

bash — multi-agent native installer
# Universal Agent Skills CLI (Claude Code, Cursor, Codex, Antigravity):
$npx skills add kennedys0/taste-engine --skill taste-engine
# Or run native zero-dependency CLI installer for all project agents:
$node bin/taste-engine.mjs install --agent all --project
# Or install globally for Google Antigravity IDE / CLI (agy):
$node bin/taste-engine.mjs install --agent antigravity --global

Option C: Tailwind CSS & shadcn/ui Presets

Scaffold official design tokens, paired color variables, and component presets directly into your frontend repository.

bash — scaffolding cli
# Scaffold presets directly into your repository:
$taste-engine init
// Or import directly into tailwind.config.js:
module.exports = {
  presets: [require('@kennedys0/taste-engine/presets/tailwind/tailwind.preset.js')],
};
