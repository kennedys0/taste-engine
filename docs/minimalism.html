How to Install

Install Minimalism or Full Engine

Choose whether you want this standalone Minimalism skill or the full 10-style autonomous Taste Engine suite for your AI coding agents.

Option A: Install Dedicated Minimalism Skill

Installs only the Minimalism style pack. Perfect if your project has already committed to this exact aesthetic and does not need a multi-style router.

bash — universal agent skills cli
# Install standalone Minimalism pack via Agent Skills CLI
$ npx skills add kennedys0/taste-engine --skill taste-style-minimalism
# Or install directly for Antigravity IDE global config
$ git clone https://github.com/kennedys0/taste-engine.git && cp -r taste-engine/optional-standalone-skills/taste-style-minimalism ~/.gemini/config/skills/

FAQ & Verification

Frequently Asked Questions

Key architectural decisions and anti-slop rules governing authentic Minimalist interfaces.

Is Minimalism just an empty screen with white space?
No. In Taste Engine, lazy emptiness (an empty screen with one centered sentence or faint gray text) is a direct failure. Authentic minimalism uses active, calibrated negative space and strict typographic scaling to present high-density information effortlessly without unnecessary box clutter.
How does Taste Engine prevent washed-out text ("anti-gray")?
We strictly enforce paired contrast switching: light mode uses deep slate ink (`#18181B`) with secondary text (`#52525B`) that strictly satisfies WCAG AA 4.5:1 ratio. In dark mode, text flips to crisp porcelain (`#F4F4F5`) against muted obsidian (`#121214`). Faint low-contrast gray text is strictly forbidden.
What is the anti-slop rule for cards and borders?
Minimalism eliminates "card inside card inside card" nesting. Related elements are grouped naturally through proximity, whitespace, and 1px hairline dividers rather than heavy shadows or multiple enclosing background boxes.
How does responsive scaling prevent bloated UI down to 320px?
On narrow mobile viewports (< 480px down to 320px), typography scales down proportionally (`clamp(1.35rem, 5.5vw, 1.75rem)` for hero headlines, `1.2rem` for section titles). The top header collapses into an accessible Hamburger Menu with a dedicated drawer, ensuring zero horizontal blowout.
Can I install just the Minimalism skill without the full engine?
Yes. Run `npx skills add kennedys0/taste-engine --skill taste-style-minimalism` to install only this standalone pack, perfectly self-contained with zero external dependencies.
